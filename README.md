## Getting Started

«Конструкторъ Сообществъ» есть приложеніе, на платформѣ Flutter (языкъ Dart) созданное, для мужей учённыхъ и любителей робототехники и разума искусственнаго. Оное служитъ устроенію сообществъ, обмѣну знаній и слѣдованію вѣстямъ чрезъ соединеніе съ потоками RSS (Habr, Hi-Tech Mail.ru, The Moscow Times). Въ орудіи семъ имѣются врата для входа, лѣтопись личная, совѣты сообществъ и созиданіе словесъ по марковскому закону въ отсутствіи связи. Обликъ его, вдохновлённый красотою грядущаго вѣка хакатона Prototip 2025, украшенъ свѣтомъ неоновымъ и движеньемъ изящнымъ. Сіе твореніе споспѣшествуетъ единенію умовъ, возвышенію мастерства и вѣдомству о новостяхъ въ дѣлѣ техническомъ.
