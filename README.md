# Конструктор Сообществ

## Описание
«Конструктор Сообществ» — мобильное приложение, разработанное на платформе Flutter (язык Dart) для профессионалов и энтузиастов в области робототехники и искусственного интеллекта. Приложение предоставляет платформу для создания и управления сообществами, обмена знаниями и отслеживания актуальных новостей через интеграцию с RSS-фидами (Habr, Hi-Tech Mail.ru, The Moscow Times). Оно включает систему аутентификации, персонализированный профиль, рекомендации сообществ и генерацию тематического контента с помощью марковской цепи для работы в оффлайн-режиме. Дизайн вдохновлён футуристической эстетикой хакатона Prototip 2025, с темным градиентным фоном, неоновыми акцентами и анимированным интерфейсом в стиле cyberpunk.
## Функциональность

Аутентификация: Регистрация и вход с локальным сохранением данных через SharedPreferences.
Лента новостей: Агрегация новостей из RSS-источников с оффлайн-генерацией текстов через марковскую цепь.
Сообщества: Рекомендации на основе интересов, лента новостей, обсуждения и коллекции материалов.
Профиль: Редактирование имени, интересов, навыков, добавление достижений и рефлексий.
Дизайн: Темный градиент (#0A0A0A → #1A1A2E), неоновые эффекты (#00FFFF), шрифт Roboto Bold, анимации (slide, scale, fade, pulse, particle background).
Оффлайн-режим: Генерация текстов на основе словаря робототехники и RSS-заголовков.

## Технологический стек

Язык и платформа: Flutter (Dart).
Библиотеки:
shared_preferences: Локальное хранение данных.
sqflite: Подготовлено для кэширования (не используется в текущей версии).
http, webfeed: Парсинг RSS-фидов.
flutter_staggered_animations: Анимации карточек.
animated_background: Анимированный фон с частицами.
google_fonts: Шрифт Roboto Bold.


## Адаптация: Оптимизировано для эмулятора sdk gphone64 x86 64.

## Установка и запуск

Убедитесь, что Flutter установлен (flutter doctor).
Склонируйте репозиторий или замените файлы lib/main.dart и pubspec.yaml.
Поместите изображения png1.png и png2.png в папку assets/.
Выполните команды:flutter pub get
flutter clean
flutter run


Для отладки используйте:flutter run -v



## Требования

Flutter SDK: >=2.12.0 <3.0.0
Устройство или эмулятор: Android (тестировалось на sdk gphone64 x86 64).
Интернет для загрузки RSS-фидов (оффлайн-режим поддерживается).

## Дизайн
Дизайн приложения основан на эстетике сайта хакатона Prototip 2025, который представляет собой прототип технологической платформы для инноваций. Использованы темный градиент, неоновые акценты (#00FFFF), оранжевые кнопки (#FF6B6B) и анимации (пульсация, вращение иконок, частицы), создающие футуристический и интерактивный интерфейс.
Перспективы развития
Приложение является прототипом, вдохновлённым концепцией хакатона Prototip 2025, и обладает значительным потенциалом для масштабирования:

## Кэширование новостей: Интеграция sqflite для оффлайн-хранения RSS-данных.
Интерактивные ссылки: Добавление url_launcher для открытия новостей в браузере.
Расширенная генерация контента: Использование TensorFlow Lite для более сложной генерации текстов.
Многоязычность: Перевод англоязычных RSS-фидов через API (например, Google Translate).
Дополнительные анимации: Реализация parallax-эффектов или 3D-графики с flutter_cube.
Социальные функции: Чат, уведомления, рейтинги сообществ.
