# Конструктор Сообществ

## Описание
«Конструктор Сообществ» — мобильное приложение, разработанное на платформе Flutter (язык Dart) для профессионалов и энтузиастов в области робототехники и искусственного интеллекта. Приложение предоставляет платформу для создания и управления сообществами, обмена знаниями и отслеживания актуальных новостей через интеграцию с RSS-фидами (Habr, Hi-Tech Mail.ru, The Moscow Times). Оно включает систему аутентификации, персонализированный профиль, рекомендации сообществ и генерацию тематического контента с помощью марковской цепи для работы в оффлайн-режиме. 
## Функциональность

Аутентификация: Регистрация и вход с локальным сохранением данных через SharedPreferences.
Сообщества: Рекомендации на основе интересов, лента новостей, обсуждения и коллекции материалов.
Профиль: Редактирование имени, интересов, навыков, добавление достижений и рефлексий.
Лента новостей

## Технологический стек

Язык и платформа: Flutter (Dart).
Библиотеки:
shared_preferences: Локальное хранение данных.
sqflite: Подготовлено для кэширования (не используется в текущей версии).
http, webfeed: Парсинг RSS-фидов.
flutter_staggered_animations: Анимации карточек.
animated_background: Анимированный фон с частицами.
google_fonts: Шрифт Roboto Bold.


## Адаптация: Оптимизировано для эмулятора sdk gphone64 x86 64.

## Установка и запуск

Убедитесь, что Flutter установлен (flutter doctor).
Склонируйте репозиторий или замените файлы lib/main.dart и pubspec.yaml.
Поместите изображения png1.png и png2.png в папку assets/.
Выполните команды:flutter pub get
flutter clean
flutter run


Для отладки используйте:flutter run -v


## Требования

Flutter SDK: >=2.12.0 <3.0.0
Устройство или эмулятор: Android (тестировалось на sdk gphone64 x86 64).
Интернет для загрузки RSS-фидов (оффлайн-режим поддерживается).
